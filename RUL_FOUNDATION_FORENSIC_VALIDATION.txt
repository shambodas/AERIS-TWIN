1. IMPLEMENTATION FINDINGS
--------------------------------------------------------------------------------
The RUL Foundation implementation in `simulation/engine_simulator.py` tracks progressive degradation natively via `wear_index`. 
- **Wear update:** Computed at every physical timestep based purely on RPM and thermal stress (no artificial penalties).
- **Failure state:** Triggers internally when `wear_index >= eol_threshold` (1.0). When `self.failed = True` is reached, the simulator outputs an overridden `EngineState` with `rpm = 0.0`, `power_kw = 0.0`, and `fault_type = "ENGINE_FAILURE"`.
- **Termination & Telemetry:** `server.py` halts further telemetry writes correctly upon detection of `ENGINE_FAILURE`.
- **RUL Calculation:** Computed retrospectively in `generate_rul_dataset.py` by subtracting elapsed `time_s` from `eol_time`, and capped at 0.0.

2. EXACT DEGRADATION EQUATION (CALIBRATED)
--------------------------------------------------------------------------------
The Phase 1B wear increment per timestep is strictly physics-based:
```python
rpm_factor = max(0.0, self.rpm / 4000.0)
thermal_factor = max(1.0, thermal_state.cht_c[0] / 150.0)
base_wear = 0.0001 * (rpm_factor ** 2) * (thermal_factor ** 2) * self.dt
wear_increment = base_wear * self.wear_rate_multiplier
```
The artificial `LOITER` phase penalty was removed. The new quadratic scaling was selected after rigorous calibration to ensure harsh profiles naturally degrade the engine faster without causing abrupt, instantaneous failure.

3. TRAJECTORY DIVERSITY ANALYSIS (RESOLVED)
--------------------------------------------------------------------------------
In Phase 1, trajectories lacked physical diversity because the simulation was fully deterministic. 
In Phase 1B, the random seed drives true latent physical variation:
- Base wear rate multiplier is varied +/- 15% per run.
- Initial wear is randomized (0.0 to 0.05).
- Operating conditions (Altitude, Throttle, Load) are subjected to continuous micro-perturbations.
This ensures that every trajectory is physically unique, avoiding deterministic overfitting.

4. HARSH-TRAJECTORY ANALYSIS (RESOLVED)
--------------------------------------------------------------------------------
Previously, HARSH trajectories failed in ~4 seconds due to the static penalty. 
With the calibrated Phase 1B physics equation, HARSH profiles now average ~53.1 seconds to EOL, spanning all degradation stages (HEALTHY → CRITICAL) meaningfully (approx 9-13 seconds spent in each stage).
